# Brand assets

`src/assets/btaa-logo.png` and `public/favicon.ico` are copied unchanged from the companion
`data-api/frontend/public/` directory. The header follows that project’s
`DESIGN.md` and BTAA entry in `frontend/theme.yaml`; only the adjacent
application name changes to GEOMG. Do not redraw or recolor the logo.

Vite embeds the header logo in the application bundle so nested admin routes and cached asset responses cannot break the brand image.
